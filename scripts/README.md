# استيراد محتوى Blogger

1. من لوحة Blogger افتح **الإعدادات > إدارة المدونة > الاحتفاظ بنسخة احتياطية للمحتوى** (قد تختلف التسمية حسب الواجهة).
2. نزّل ملف التصدير XML الأصلي واحتفظ بنسخة غير معدّلة منه.
3. لا تحذف أو تغيّر الموقع القديم أثناء النقل.
4. يلزم تحويل كل منشور إلى Markdown مع حفظ: العنوان، المحتوى الكامل، تاريخ النشر والتحديث، الصور، التصنيفات، الرابط القديم، وحالة النشر.
5. بعد الاستيراد، راجع خريطة الروابط القديمة والجديدة يدويًا، ثم أضف تحويلات 301 الصحيحة إلى `public/_redirects`.

لا تعتبر عناوين المقالات الظاهرة في نتائج البحث جردًا كاملًا للموقع. لا يمكن اعتماد ترحيل المحتوى أو تحويل الروابط قبل الحصول على تصدير Blogger الكامل.
